User Vaults are live on Liv4All 🔐

Your AI agent needs access to your tools, but that shouldn't mean handing over your keys.

We just shipped User Vaults: per-user encrypted credential storage that lets your agent securely access API keys, passwords, OAuth tokens and whatever else your integrations need. We never see them in plaintext.

In this video, I store my DNSimple API token and ask my agent to pull my domains.
