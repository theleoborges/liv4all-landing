O OpenClaw é deliberadamente leve. Os requisitos mínimos são cerca de 2 cores de CPU, 2 GB de RAM e 2 GB de armazenamento, e ele roda em qualquer sistema operacional. O Ubuntu 24.04 é o SO recomendado, principalmente porque tem bom suporte e é o que a maioria dos guias assume.

Ele pode ser assim modesto porque a computação cara, a inferência do modelo, acontece na nuvem do provedor de LLM via API. Seu servidor orquestra o loop do agente e guarda estado; ele não roda um modelo. É por isso que uma máquina pequena e barata basta.

## Como funciona

O [OpenClaw](https://github.com/openclaw/openclaw) roda como um processo (via Docker ou Node) que gerencia o loop do agente: receber mensagens, chamar o LLM, executar skills e persistir memória. Nada disso é faminto por CPU ou RAM, então o gargalo quase nunca é o seu hardware. É a sua cota de API do LLM e a sua conexão de rede.

Uma linha de base prática:

- **CPU:** ~2 cores.
- **RAM:** ~2 GB (mais folga ajuda se você roda muitas skills).
- **Armazenamento:** ~2 GB (arquivos de memória e logs crescem devagar).
- **SO:** qualquer um; Ubuntu 24.04 recomendado.
- **Rede:** HTTPS de saída estável para as APIs do seu LLM e dos canais.

Praticamente qualquer VPS moderno passa nesse teste. Para escolher um, veja [melhor VPS para um agente de IA](/pt-br/answers/best-vps-for-ai-agent).

## Perguntas comuns

### Posso rodar o OpenClaw em um Raspberry Pi?
Se ele atender a ~2 cores e 2 GB de RAM, sim. Os requisitos são baixos o bastante para computadores de placa única pequenos.

### Precisa de GPU?
Não. A inferência acontece via API do LLM, então nenhuma GPU local é necessária.

### Que SO devo usar?
Qualquer um funciona; o Ubuntu 24.04 é recomendado por suporte e alinhamento com a documentação.

### Quanto armazenamento ele usa com o tempo?
Pouco. Arquivos de memória e logs crescem devagar; 2 GB é um bom ponto de partida.

### Qual VPS é o melhor?
Qualquer um que atenda aos requisitos mínimos. [Melhor VPS para um agente de IA](/pt-br/answers/best-vps-for-ai-agent) compara as opções.
