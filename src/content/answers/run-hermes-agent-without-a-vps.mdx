You don't strictly need a VPS to run [Hermes Agent](/answers/what-is-hermes-agent). It supports several terminal backends, so you can run it locally on your own machine or push it to serverless platforms. What you can't avoid, if you self-host, is owning the deploy: the install, the upgrades and the debugging.

So there are really two questions hiding here. Do you want to run it somewhere other than a rented server? Or do you want to not run it at all?

## How it works

[Hermes Agent](https://github.com/nousresearch/hermes-agent) offers six terminal backends: local, Docker, SSH, Daytona, Singularity and Modal. That means you have choices beyond a classic VPS:

- **Local:** run it on your own laptop or desktop. Fine for testing, but it only works while that machine is on and online, so a persistent always-on agent is awkward.
- **Serverless:** Modal and Daytona let you run it without managing a long-lived server. You still configure and maintain the deployment, but you skip provisioning a box.
- **GPU cluster:** for heavier workloads, if you have the hardware.

Even on serverless, self-hosting carries roughly 1–3 hours a month of upkeep: OAuth token expiry, codebase updates, and debugging when a skill fails. See [self-host AI agent maintenance](/answers/self-host-ai-agent-maintenance) and [do I need a server for a personal AI agent](/answers/do-i-need-a-server-for-a-personal-ai-agent).

## Worked example

| Approach | Server to rent? | Always-on? | Ops on you? |
| --- | --- | --- | --- |
| Hermes Agent, local | No | Only when machine is on | Yes |
| Hermes Agent, serverless (Modal/Daytona) | No (managed compute) | Yes | Yes |
| Hermes Agent, VPS | Yes ($5+/mo) | Yes | Yes |
| Managed agent (e.g. Liv) | No | Yes | No |

If the point of avoiding a VPS is avoiding ops entirely, only the last row gets you there. A [managed personal AI agent](/answers/self-hosted-vs-managed-ai-agent) runs the infrastructure for you and stays always-on.

## Common questions

### Can Hermes Agent run on my laptop?
Yes, via the local backend. The catch is that it only runs while your laptop is on and connected, so it isn't a true always-on agent.

### What serverless options does it support?
Modal and Daytona, among its six terminal backends. These let you run it without provisioning a long-lived VPS.

### Does serverless remove maintenance?
No. You still own configuration, OAuth tokens and updates. Serverless removes server provisioning, not the upkeep.

### What's the cheapest way to self-host it?
A $5 VPS, or local on hardware you already own. Add LLM API usage on top, typically keeping total infra under $100/month.

### What if I want zero infrastructure?
Use a managed agent. See [how much does a managed AI agent cost](/answers/how-much-does-a-managed-ai-agent-cost) for fixed pricing versus self-host costs.

### Is a managed agent as private as running it myself?
Different trade-off. Liv uses encrypted per-user vaults, revocable Google OAuth, and doesn't use your data to train models; it passed Google [CASA Tier 2](/answers/what-is-casa-tier-2-gmail).
